## Hometask 4
### Subtasks: 
Create ECR repository
Put jenkins/jenkins image to ECR
Create ECS cluster (FarGate type)
Create Task Description for jenkins container
Create Service on port 8080 for jenkins
Apply DNS domain name
Write terraform code for your function

### Prereqiusites:  
1. AWS account
2. GitHub account
3. Registered DNS domain
4. AWS CLI installed and configured
5. Terraform installed and configured for your AWS account 
6. Have jenkins docker image prepared and names as jenkins

### Run project:
1. _terraform plan_
2. _terraform apply_
3. Check your service with browser
4. Use _terraform destroy_ to free-up your recourses
